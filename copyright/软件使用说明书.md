# 堡垒机安全远程运维管理平台 V1.0

## 软件使用说明书

---

### 一、软件概述

堡垒机安全远程运维管理平台（Bastion Host）是一套面向企业 IT 运维的 Web 化远程访问管理系统。平台集中管理 SSH/RDP/数据库等异构资产的访问权限，提供浏览器原生的远程终端、SQL 查询工作台、会话录像回放、操作审计追溯等功能，满足 SOC 2、等保三级对企业运维安全的合规要求。

**主要功能模块**：

| 模块 | 功能说明 |
|------|---------|
| 仪表盘 | 系统态势总览：资产、会话、查询、安全告警实时统计 |
| 资产管理 | SSH/RDP/数据库资产的注册、分组、连接测试、CSV 导入 |
| 权限管理 | 用户/角色/资产授权的精细化 RBAC 控制 |
| 远程终端 | 浏览器内 SSH/RDP 连接，零客户端安装 |
| 数据库管理 | SQL 查询编辑器（智能补全）、库表浏览、数据导入导出 |
| 安全审计 | 操作日志、命令日志、登录日志的查询与 CSV 导出 |
| 会话回放 | SSH 会话 asciicast 录像与 RDP 会话回放 |

### 二、运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux (推荐) / Windows / macOS |
| 容器引擎 | Docker 20+ + Docker Compose v2 |
| 浏览器 | Chrome 90+ / Edge 90+ / Firefox 100+ |
| 硬件建议 | 2 核 CPU、4 GB 内存、20 GB 磁盘 |

### 三、安装与启动

```bash
# 1. 克隆项目
git clone https://github.com/yangshifei/bastion-host.git
cd bastion-host

# 2. 配置环境变量（可选）
cp .env.example .env
# 编辑 .env 中的密码和密钥

# 3. 启动所有服务
docker compose up -d

# 4. 访问
浏览器打开 http://localhost
默认管理员: admin / admin123
```

### 四、功能操作说明

#### 4.1 仪表盘

登录后默认进入仪表盘，顶部展示核心统计卡片（资产总数、在线资产、活跃会话、今日查询、用户数、危险命令），中部展示 7 日会话趋势柱状图、资产类型分布环形图、命令安全比例图，底部提供快捷入口和最近活动记录。

![仪表盘](screenshots/dashboard.png)

#### 4.2 资产管理

左侧导航点击「资产管理」进入。页面顶部显示资产分类统计卡片，主体为可展开的分组表格。

- **添加资产**：点击右上角「添加资产」按钮，在弹出的对话框中填写资产名称、类型（主机/数据库）、连接地址、端口、用户名密码、分组等信息。
- **测试连接**：在资产行的操作列点击刷新图标，可测试 TCP 连通性或数据库连接。
- **编辑/删除**：点击编辑图标修改资产信息，点击删除图标移除资产。
- **导入 CSV**：支持批量导入资产，CSV 格式包含名称、主机、端口、协议等列。

![资产管理](screenshots/assets.png)

#### 4.3 SSH 终端

左侧导航点击「SSH 终端」进入。页面顶部有资产选择器，选择需要连接的 SSH 资产后点击「连接」按钮。

- 连接成功后在浏览器内的终端窗口即可直接操作远程服务器
- 支持终端清屏、自动登录、会话文件管理
- 点击「文件」按钮可打开 SFTP 面板，进行文件上传下载
- 点击「断开」结束会话

#### 4.4 数据库管理

左侧导航点击「数据库管理」进入。顶部展示数据库实例列表，点击某实例的「SQL 窗口」进入查询工作台。

**查询工作台功能**：
- **SQL 编辑器**：基于 Monaco Editor，支持关键字、表名、字段名、函数名的智能自动补全
- **Ctrl+Enter 执行**：选中部分 SQL 按 Ctrl+Enter 仅执行选中部分；无选中时执行全部
- **对象树**：左侧展示当前数据库的表、视图、存储过程列表，点击即可预览数据或查看结构
- **导入导出**：支持 CSV 和 SQL 格式的数据导入导出

#### 4.5 安全审计

左侧导航点击「安全审计」进入。提供三个 Tab 页：

- **操作日志**：记录所有用户对资产的增删改查操作，支持按操作类型、时间范围筛选
- **命令日志**：记录 SSH 终端中执行的所有命令，自动标注危险命令（rm -rf、DROP TABLE 等）
- **登录日志**：记录所有登录尝试（含成功和失败），支持安全分析

支持 CSV 导出所有审计数据。

#### 4.6 会话回放

记录每次 SSH 和 RDP 远程会话的完整过程：
- SSH 会话以 asciicast v2 格式录制，可在浏览器中倍速播放
- RDP 会话通过 Guacamole 协议录制
- 支持按时间、用户、资产筛选

### 五、用户角色说明

| 角色 | 权限范围 |
|------|---------|
| admin（管理员） | 全部功能：资产管理、用户管理、授权管理、审计、所有连接入口 |
| operator（运维人员） | SSH/RDP 连接、SQL 查询、自有授权资产 |
| auditor（审计员） | 只读访问：审计日志、命令日志、会话回放、仪表盘 |

### 六、技术架构

| 层级 | 技术栈 |
|------|--------|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS + TDesign + Monaco Editor |
| 后端 | Node.js + Express + TypeScript + WebSocket (ws) |
| 数据库 | MySQL 8.0（堡垒机元数据） + MySQL/PG/MSSQL（目标数据库） |
| 远程协议 | SSH (ssh2 + xterm.js) / RDP (Apache Guacamole) |
| 部署 | Docker Compose（MySQL + guacd + nginx + bastion-app） |
